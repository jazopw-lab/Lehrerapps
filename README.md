# Lehrerapps – FOSBOS Weiden

Werkzeuge für Lehrkräfte, gehostet über GitHub Pages: https://jazopw-lab.github.io/lehrerapps/

- `notentracker/` – Notentracker: Mitarbeit, Sitzplan, Gruppen, mündliche Ausfragen (Englisch/Deutsch), PDF-Protokolle. **Passwortgeschützt** (AES-verschlüsselt mit StatiCrypt).
- `news-in-your-feed/` – Englisch F12, U1 M6 „News in Your Feed“, Lehrerversion zur Stundenführung (Beamer/iPad): Lösungen per Klick bzw. Presenter-Clicker, Text mit Originalzeilen, Phasen-Timer, Notizen, Zufallsauswahl. **Passwortgeschützt** (StatiCrypt, eigenes Salt; enthält Lösungen und Zeitungstext – nur verschlüsselt ablegen).
- `american-exceptionalism/` – Englisch F13, „The death of American exceptionalism“ (Abitur 2025, Text III), Lehrerversion zur Stundenführung (45 Min.): Lösungen per Klick (Task 4 und HA = Abitur-Erwartungshorizont), Text mit Zeilen wie auf dem Textblatt, Phasen-Timer, Notizen, Zufallsauswahl, QR zur Schüler-App. **Passwortgeschützt** (StatiCrypt, eigenes Salt; enthält Lösungen und Zeitschriftentext – nur verschlüsselt ablegen).

Die Apps speichern keine Daten auf einem Server; alle Eingaben bleiben im Browser des verwendeten Geräts. Die Seiten sind für Suchmaschinen gesperrt (`noindex`).

Weitere Werkzeuge kommen jeweils in einen eigenen Ordner und werden auf der Startseite `index.html` verlinkt. Geschützte Apps nur verschlüsselt hier ablegen.
